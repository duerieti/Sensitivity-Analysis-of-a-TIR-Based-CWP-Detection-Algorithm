Morris is much cheaper but no secundary effects. So its not possible to differentiate between nonlinearity and interactive effects. Sigma can just give you a hint about it. Here I also need to state that variance analysis is generally well explored for models which have a onedimensional outputs. Spatial models are however inherently multidimensional due to the space and time dimensions which these models often occupy. This missmatch can be addressed suing two strategies. Some researchers produce index maps, where each pixel is beeing treated as an idependent model output and the sensitivity analysis is performed for every pixel. The result of this is a map showing model sensitivity in the spatial domain. This is very elegant but also features high computational costs, as perfoming a sensitivity analysis for every pixel in a raster can become very costly as the raster grows. (In my raster there are for instance 6 bilion pixles). Another approach is to lump the spatial output into a onedimensional metric, compute the senistivity of this lumped statistc. This is far easier and computationally less exaustive. But as a trade of the spatial information gets lost in the process. In this thesis, the later is taken into account and a lumped parameter statistic is beeing comptuted

If different color heues are visible, then this indicates regions which are not always present and are changing depending on the parameter combination set. These are the interesting patches where a sensitivity analysis can be performed, the ones that do not show any change at all, these are also not of use for the analysis as there is not variability in the results to begin with. The selection followed a manual cirteria. First decide wheter change affected or not. Then decide wheter tributary effected or not. Lastly it helps to remove bias. Toblers first law of geography. "Everyhting is related to everything but close things are more related than distant things in space". So if I sample one coldwater patch the and observe its sensitiviy with respect to input parameters, then the neighbouring coldwater patches are very likely to behave similarly just because they are at a similar location and not necessairly because their mode of origin. So sampling all these coldwater patches as indiviudal entities introduces a bias do to geographic closenes and toblers first law.

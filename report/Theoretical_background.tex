\section{Sensitivity Analysis}

According to Saltelli et al. sensitivity analysis is ``The study of how uncertainty in the output of a model [\dots] can be apportioned to different sources of uncertainty in the model input'' \citep{saltelli_sensitivity_2004}. This definition rests on a broad notion of what counts as a model input: in sensitivity analysis, everything that causes variation in the output of the model is classified as an input \citep{saltelli_global_2007}. Providing an example: if a linear regression of a target variable $Y$ is performed, then not only are the predictors $X_1, \dots, X_n$ considered as model inputs, but also the parameters $\theta_1, \dots, \theta_n$ that correspond to the predictors. So the model:

\begin{equation}
	Y = f(X_1, X_2, \theta_1, \theta_2)
	\label{eq:model_with_params}
\end{equation}

would have four model inputs from the view of sensitivity analysis.

Sensitivity analysis provides a range of benefits. Firstly it allows the modeller to apply a strategy called ``Factor Fixing'': if the model output $Y$ is found to be independent of one or multiple inputs $X_i$, then these can be set to fixed constants,  making sensitivity analysis a tool for model simplification \citep{saltelli_global_2007}. Secondly, sensitivity analysis generally improves model validity by identifying highly influential and therefore critical model components \citep{ligmann-zielinska_spatially-explicit_2013}.

\section{The Morris Method}

The Morris method belongs to the group of screening methods in sensitivity 
analysis. Screening methods require only a small number of model evaluations, 
making them computationally cheap and therefore well suited to models that are 
expensive to run \citep{saltelli_global_2007, campolongo_effective_2007}. The 
resulting sensitivity indices cannot be interpreted quantitatively, but they do 
allow for a qualitative, ordinal ranking of which model inputs are more 
important than others \citep{campolongo_screening_2011}. As a global method, 
Morris explores the entire input space by varying all input parameters 
simultaneously across their plausible ranges, meaning that sensitivity scores 
reflect average behaviour across the full parameter space rather than being tied 
to a single point \citep{saltelli_how_2010}. The following explanation of the 
Morris method closely follows \citep{saltelli_global_2007} and is explained more 
explicitly in chapter 3 of their book.

\subsection{Elementary Effects and the Sampling Grid}

At the core of the Morris method sits a $k$-dimensional model $Y$ with inputs $X_1, \dots, X_k$. The model inputs are defined in the $k$-dimensional unit cube, meaning that $X_i$ can take on a value in the interval $[0,1]$. It is worth pointing out, that every model with a continuous input can be scaled to the $[0,1]$ range, which makes the unit cube a great place to define methods. In the Morris method, this input space is discretized into a grid $\Omega$, which is used as a basis for the computation of so-called elementary effects.

An elementary effect of the $i$th input parameter $X_i$ is defined as:

\begin{equation}
	EE_i = \frac{Y(X_1, X_2, \dots, X_{i-1}, X_i + \Delta, \dots, X_k) - Y(X_1, X_2, \dots, X_k)}{\Delta}
\end{equation}

Where $\Delta$ represents some step along the grid $\Omega$. Figure~\ref{fig:morris_grid}, taken from \citep{saltelli_global_2007}, shows an example of such a grid for a two-parameter, four-level case.

\begin{figure}[h]
	\centering
	\includegraphics[width=0.7\textwidth]{Bilder/morris_grid.png}
	\caption{An example grid $\Omega$. The grid features two parameters $X_1$, $X_2$, meaning that it is a two-dimensional grid. Further, it features four levels ($p = 4$). The step length $\Delta$ chosen here is $\frac{2}{3}$ and indicated by the arrows.}
	\label{fig:morris_grid}
\end{figure}

The Morris method occupies itself with finding the statistical distribution of each of the $i$ elementary effects. $\mathcal{F}_i$ is thereby used to denote the distribution of $EE_i$, in other words $\mathcal{F}_i \sim EE_i$ \citep{saltelli_global_2007}.

\subsection{Trajectory-Based Sampling}

To populate $\mathcal{F}_i$ with multiple samples of $EE_i$, the Morris method uses an efficient trajectory-based sampling design that obtains as many elementary effects $EE_i$ from as few model evaluations as possible. The exact mathematical formulation of how trajectories are constructed is beyond the scope of this thesis; a visual understanding is sufficient. Figure~\ref{fig:saltelli_trajectory_grid}, taken from \citep{saltelli_global_2007}, shows an example trajectory through a three-dimensional sampling grid.

\begin{figure}[H]
	\centering
	\includegraphics[width=0.7\textwidth]{Bilder/satteli_trajectory_grid.png}
	\caption{An example Morris trajectory through a three-dimensional sampling grid ($k = 3$, $p = 6$). The trajectory consists of $k+1 = 4$ points.}
	\label{fig:saltelli_trajectory_grid}
\end{figure}

From this figure it becomes visible that a trajectory consists of $k+1$ points $\mathbf{x}^{(1)}, \mathbf{x}^{(2)}, \dots, \mathbf{x}^{(k+1)}$, where $k$ is the dimension of the sampling grid. Each point differs from its predecessor by a step of $\Delta$ in exactly one grid direction, so that consecutive points differ in only one model input $X_i$. The trajectory is constructed such that each dimension of the grid is stepped along exactly once. Each trajectory yields exactly $k$ elementary effects $EE_i$ -- one for each parameter spanning the sampling grid -- and requires $k+1$ model evaluations.

To build up $\mathcal{F}_i$ for every factor, $r$ such trajectories are generated. Since each trajectory contributes exactly one elementary effect per factor, each $\mathcal{F}_i$ ends up containing $r$ samples. The total number of model evaluations required therefore is:

\begin{equation}
	N = r \cdot (k+1)
	\label{eq:morris_runs}
\end{equation}

\citep{saltelli_global_2007}.

\subsection{Choosing $\Delta$ and $r$}
\label{sec:choosing_delta_r}

The choice of $r$ and $\Delta$ is not independent of $p$. When $p$ is chosen to be even, the choice $\Delta = \frac{p/2}{p-1}$ is ideal, as it has the additional property of guaranteeing equal-probability sampling from the grid, meaning that all grid levels are sampled with equal probability across the $r$ trajectories \citep{saltelli_global_2007}. There is no clear rule regarding the number of trajectories $r$ to pick. Generally, as the number of levels $p$ in the grid increases, the number of trajectories $r$ also needs to increase. Otherwise, increasing $p$ serves little purpose, as the grid will not be sufficiently explored to feature all levels if the number of trajectories is too small \citep{saltelli_global_2007}. Generally, the number of trajectories is usually chosen somewhere between 10--50 \citep{campolongo_effective_2007}.

\subsection{Sensitivity Measures: $\mu$, $\sigma$, and $\mu^*$}

Once the distributions $\mathcal{F}_i$ have been mapped out, statistical measures can be computed, specifically the mean $\mu_i$ and the standard deviation $\sigma_i$ of $\mathcal{F}_i$ are of interest. These two statistical measures together already allow for reasonable insight into the influence of the $i$th parameter $X_i$, which corresponds to the $i$th elementary effect $EE_i$, onto the model:

If $\mu_i$ deviates strongly from $0$, then this means that the elementary effect $EE_i$ generally takes on non-zero values and therefore that the model output changes notably when a step of $\Delta$ is performed along the dimension spanned by $X_i$. This ultimately means that changes in $X_i$ generally affect the model output $Y$ considerably, and that $X_i$ therefore receives a high sensitivity score.

If $\sigma_i$ is large, this means that the distribution $\mathcal{F}_i$ is spread out considerably over a larger range. This indicates that the computed elementary effects $EE_i$ generally differed depending on their location in the grid. This behaviour points either to nonlinearity regarding $X_i$ or to the fact that $X_i$ interacts with other input parameters. Which of the two effects is responsible for the high standard deviation -- or whether both contribute simultaneously -- cannot be determined, which is a shortcoming of the Morris method \citep{saltelli_global_2007}. Figure~\ref{fig:mu_sig_example} provides a visual example of possible $\mathcal{F}$ along with the associated $\mu$ and $\sigma$ values and their corresponding interpretation.

\begin{figure}[H]
	\centering
	\includegraphics[width=1\textwidth]{Bilder/example_grid_mu_sigma_vairation.png}
	\caption{Four example distributions $\mathcal{F}_i$ of a parameter $X_i$,
		illustrating how $\mu$ and $\sigma$ jointly characterise parameter influence.
		\textit{Top left}: a large effect obscured by symmetry. \textit{Top right}: a large effect with no nonlinearity 
		or interactions. 
		\textit{Bottom left}: a large effect with nonlinearity or interactions. \textit{Bottom right}: a small effect 
		with no nonlinearity or interactions.}
	\label{fig:mu_sig_example}
\end{figure}

Situations can occur where $\mathcal{F}_i$ contains many extreme values, yet the distribution is symmetric around zero. One such example is visualized in the upper-left plot of Figure~\ref{fig:mu_sig_example}. In such cases, computing the mean value $\mu_i$ yields a value close to zero, leading to the assumption that the parameter $X_i$ is noninfluential. This would be a faulty assumption, as the sampled elementary effects $EE_i$ are substantial in magnitude but cancel each other out. This phenomenon can be detected by always taking $\sigma_i$ into consideration, since in this scenario $\sigma_i$ is large. It is, however, more common to additionally sample a distribution $\mathcal{G}_i$, which captures the magnitude of the elementary effects $|EE_i|$. We then compute the mean of this distribution, $\mu^*_i$, which can be interpreted like $\mu_i$. Since it only captures magnitude, this distribution however never features negative values, and cancellation effects can therefore not occur \citep{saltelli_global_2007}. Figure~\ref{fig:mu_mu_star} provides a visual example of this mechanism.

\begin{figure}[H]
	\centering

	\caption{The difference of $\mu$ and $\mu^{\star}$ visualized with their underlying distribution $\mathcal{F}_i$ and $\mathcal{G}_i$. While the $\mu$ lies at around zero, $\mu^{\star}$ significantly deviates from zero.}
	\label{fig:mu_mu_star}
\end{figure}

\section{Application to Spatial Models}

The Morris method, like most global sensitivity analysis methods, is defined for models with a scalar output: a single value $Y$ is required for each model evaluation \citep{saltelli_global_2007}. The CWP detection algorithm, however, produces a spatially distributed output. Applying the Morris method to such a model therefore requires a spatial aggregation step to aggregate the spatial output to a scalar value, e.g. using a statistical aggregation function such as the mean \citep{lilburne_sensitivity_2009}.

\section{Coldwater Patches}

Cold water patches (CWPs) are areas in rivers and streams where the water temperature is measurably colder than that of the main channel. The temperature difference used to define a CWP varies across the literature but is typically set between 0.5 and 3 degrees Celsius below the main channel temperature \citep{casas-mulet_unmanned_2020, wawrzyniak_effects_2016}. Cold water patches are not automatically cold water refugia. Cold water refugia are cold water patches that are actively used by cold-water organisms for thermal relief \citep{mejia_closing_2023}. The ecological importance of cold water refugia is expected to increase as river temperatures rise due to climate change \citep{kurylyk_preserving_2015}. CWPs can arise from a range of physical mechanisms. A common cause is the inflow of a colder tributary-. Other generating mechanisms include groundwater upwelling, lateral seeps or hyporheic exchange \citep{mejia_closing_2023}.
